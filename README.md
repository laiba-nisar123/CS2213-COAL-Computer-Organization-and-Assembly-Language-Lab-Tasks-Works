## 📖 Repository Overview

This repository documents the laboratory work completed for the COAL course. It brings together fourteen structured labs in 8086 Assembly Language, developed and tested in the EMU8086 emulator.

The labs build gradually from the basics of assembly programming to more advanced concepts. Each lab folder contains the `.asm` source files, screenshots of the program output, and a short README.

## 🎯 Learning Outcomes

- Understand the organization of the 8086 processor and its registers.
- Write, assemble, and debug assembly programs with correct syntax and segments.
- Apply different addressing modes to access registers, memory, and immediate data.
- Use software interrupts for input and output operations.
- Perform arithmetic operations, including multiplication and division.
- Declare and manipulate variables, data types, and arrays.
- Implement control flow using loops, nested loops, and conditional jumps.
- Use the stack and design modular programs with procedures.
- Interpret the FLAGS register to understand instruction results.
